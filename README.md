# AI Web Chatbot

An AI-powered chatbot web application built using Python, Flask, HTML, CSS, and JavaScript.

## Features

* AI chatbot responses using Cohere API
* Internet search integration using DuckDuckGo
* Chat memory system
* Typing animation effect
* Dark mode and light mode
* Rename chatbot feature
* Responsive web interface
* Enter key support

## Technologies Used

* Python
* Flask
* HTML
* CSS
* JavaScript
* Cohere API
* DuckDuckGo Search

## Project Structure

```bash
chatbot_project/
│
├── chatbot_app.py
├── requirements.txt
│
├── templates/
│   └── index.html
│
├── static/
│   └── style.css
```

## Installation

Install required packages:

```bash
pip install flask cohere duckduckgo-search
```

## Run the Project

```bash
python chatbot_app.py
```
